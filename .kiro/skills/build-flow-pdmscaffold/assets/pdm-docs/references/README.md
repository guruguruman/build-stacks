# References

ここには、PdM正本の判断材料を置きます。参照資料そのものは正本ではありません。

## 対象

- 市場・競合・代替調査
- インタビュー、観察、ユーザビリティテスト
- 財務・価格・コストの仮説
- 仮説台帳、意思決定前の分析
- 外部出典と確認ログ

## 命名

- 通常資料: `{topic}-{YYYY-MM-DD}.md`
- 継続台帳: `{topic}-register.md` または `{topic}-ledger.md`
- 再利用雛形: `{topic}-template.md`
- すべて小文字ケバブケース

## 各資料に必要な情報

1. 目的と判断したい論点
2. 調査日・確認日
3. 対象、範囲、方法
4. 事実・観察
5. 推定・解釈
6. 未検証の仮説
7. 制約・バイアス・不足
8. 正本へ反映する判断
9. 出典

## 正本への反映

- 採用した結論だけを該当正本へ要約する
- 正本側から参照資料へリンクする
- 反映日と反映先を参照資料へ記録する
- 古くなった数値・仕様・制度は、重要判断の前に再確認する
